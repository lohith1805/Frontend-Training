## Project Overview

## Features
- ✅ Responsive Design (mobile, tablet, desktop)
- ✅ Mobile Navigation (hamburger menu with animation)
- ✅ Gradient Backgrounds (hero, buttons, badges, cards)
- ✅ Hover Effects (cards, nav links, images, buttons)
- ✅ Modern Typography (Syne + DM Sans from Google Fonts)
- ✅ Responsive Images (Unsplash CDN with proper sizing)
- ✅ CSS Flexbox (navbar, stats, values, footer)
- ✅ CSS Grid (services grid, about grid, footer columns)
- ✅ Media Queries (1024px, 768px, 480px breakpoints)
- ✅ Scroll Reveal Animations (IntersectionObserver)
- ✅ Active nav link highlighting on scroll
- ✅ Smooth scroll with fixed-nav offset
- ✅ Contact form with success feedback

## Technologies Used
- **HTML5** — Semantic elements, accessibility attributes
- **CSS3** — Variables, Flexbox, Grid, Animations, Media Queries
- **Vanilla JavaScript** — No frameworks/libraries
- **Google Fonts** — Syne (display), DM Sans (body)
- **Unsplash** — Stock photography
