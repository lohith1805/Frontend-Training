# ZenField Landing Page

Responsive landing page recreated using HTML, CSS, Bootstrap, and JavaScript.

## Folder Structure

```
zenfield-bootstrap-separated/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Notes

- Bootstrap CSS and JS are included through CDN links.
- Custom CSS is separated into `css/style.css`.
- Custom JavaScript is separated into `js/script.js`.
- The design and layout are kept the same as the uploaded website.
