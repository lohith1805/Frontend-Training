# ZenField Admin Dashboard

Static admin dashboard built with HTML5, CSS3, Bootstrap, and JavaScript.

## Pages
- `index.html` - TailAdmin-style eCommerce dashboard
- `tables.html` - dashboard tables and user management table
- `charts.html` - chart visualizations
- `analytics.html` - all visualizations in one analytics page
- `profile.html` - profile settings with working Save Changes
- `signin.html`, `signup.html` - authentication pages

## Notes
- No React, Vite, npm, or Node setup is required.
- Open `index.html` directly or run with a simple local server.
- Dark/light mode and profile details are stored in localStorage.
