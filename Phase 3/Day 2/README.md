# Phase 3 Day 2 - Employee Management Admin Dashboard

This project is built using HTML, CSS, JavaScript, Bootstrap 5, Bootstrap Icons, Chart.js, and Google Fonts.

## Updated Requirements Implemented
- Converted the earlier single-page UI into a multi-page admin dashboard.
- Added a fixed side navbar with separate pages.
- Changed the font from Syne/DM Sans to Poppins sans-serif.
- Added Dashboard, Add Employee, Employee Profiles, Employee Table, and Analytics pages.
- Added visual graphs using Chart.js.
- Added search and filters on both Employee Profiles and Employee Table pages.
- Add Employee button in the Employee Table page routes to `registration.html`.
- Added responsive sidebar behavior for mobile screens.

## Pages
- `index.html` - Dashboard
- `registration.html` - Employee Registration Form
- `profiles.html` - Employee Profile Cards with search and filters
- `employees.html` - Employee Table with search, filters, and Add Employee button
- `analytics.html` - Charts and visual data

## How to Run
Open `index.html` in a browser. No build step is required.
